# 知行化学 · 高中化学智慧教学平台

面向高中化学真实课堂的 AIGC 教学演示原型。教师上传学生作业照片，平台调用多模态模型给出等级、三维度评语和逐题解析，并自动更新学生档案、生成班级共性分析、沉淀匿名优秀答案；课堂教学模块接入了 7 个高中必做实验的交互仿真；课后服务模块接入了“不直接给答案”的步进式答疑助手。未配置 API Key 或接口不可用时，自动使用预置演示数据，保证整套页面可以完整走通。

> 本作品为华中师范大学首届（2026）大学生 AIGC 教学应用竞赛场景下的教学演示原型，不是赛事官方平台。所有学生、作业与批改数据均为虚构演示数据。

## 一、一分钟开始

1. 把整个 `chemistry-platform` 文件夹复制到电脑上（不要只复制单个 HTML 文件）。
2. 双击 `index.html`，用 Chrome 或 Edge 打开。
3. 第一次使用先点“注册新账号”，选择“教师”或“学生”，填写姓名、账号、密码和班级。
4. 登录后进入对应工作台。教师从“作业批改”开始，学生从“我的作业”开始。
5. 不想注册时，直接点登录页上的演示账号按钮：
   - 教师：`teacher` / `123456`
   - 学生：`student` / `123456`
   - 学生：`student2` / `123456`
   - 学生：`student3` / `123456`
6. 需要调用真实 AI 时，进入右上角“设置”，填写对应模型平台的 API Key（默认 DeepSeek，模型名 `deepseek-flash`），也可以点“模型预设”换成智谱、Gemini 或硅基流动；保存后再回到“作业批改”上传 JPG/PNG 作业照片。
7. 不填 Key 也能演示：批改页点“使用演示数据批改”，或在 API 调用失败时由页面自动回退到演示结果。
8. 课后答疑：进入“课后服务 → 课后答疑助手”，点一道示例题 → “开始拆解”，按“方向提示 → 关键原理 → 规范解析”逐层练习；不填 Key 也能完整演示。
9. 想直接看实验仿真：登录后点顶部“课堂教学”→“进入实验仿真实验室”，7 个实验都不需要 API Key。

### 运行环境

- 不需要安装框架、数据库或 Node.js。
- 纯 HTML + CSS + 原生 JavaScript，无外部 CDN、无第三方前端库。
- 推荐 Chrome / Edge 最近版本。
- 所有数据保存在当前浏览器的 `localStorage`，不上传到本平台服务器（调用真实模型时只把题目文字、作业图片与提示词发送到所配置的接口）。
- 直接双击打开时，登录、档案、作业、优秀答案、报告等功能均可用。若浏览器对 `file://` 发起跨域请求有限制，真实 API 调用可能被拦截；此时平台会自动回退演示数据。需要稳定调用真实接口时，建议用任意静态文件服务器打开本文件夹（例如 VS Code 的 Live Server），或在支持跨域的接口地址 / 反向代理下使用。

## 四、作业与评价模块怎么演示

### 教师端一条完整路径

1. 用 `teacher / 123456` 登录。
2. 工作台可见 2 份待批改作业；点“进入批改工作台”或“去批改”。
3. 在“上传与批改”中选择学生、作业批次，可填写学生自述。
4. 不填 Key 时点“使用演示数据批改”；填了 Key 可上传 JPG/PNG 后点“开始 AI 多模态批改”。
5. 等待结果：等级（A+ / A / B+ / B / C+ / C）、分数环、三维度评语（知识准确性 / 思维完整性 / 规范性）、80—120 字整体评价、逐题解析（题目、学生作答、判定、错因、正确思路）、薄弱点标签。
6. 在任意题目下点“标记为优秀答案”，填写教师评语，即可匿名展示到优秀答案墙。
7. 在右侧“班级共性分析”勾选至少 2 份同班已批改作业，点“生成共性报告”，跳转到 `common-issues.html` 查看 Top 5、匿名错例和讲评建议。
8. 在 `excellent-answers.html` 可以取消某条优秀答案的展示，取消后进入“已隐藏的答案”，仍可重新展示。

### 学生端一条完整路径

1. 用 `student / 123456` 登录。
2. 进入“我的作业”，选择批次，填写自述，可上传图片/PDF；没有照片也可以直接“提交作业”走演示。
3. 提交后显示“待批改”，记录出现在“我的提交记录”中。
4. 教师在批改页处理该提交后，学生回到“我的作业”即可看到等级、评语、逐题解析和薄弱点。
5. 学生可在“优秀答案墙”查看匿名后的优秀作答与教师评语；学生端没有取消展示按钮。

### 化学学科批改约束

发送给模型的提示词已写入以下要求：

- 方程式箭头区分：不可逆反应用“→”，可逆反应用“⇌”，计算关系式用“=”；
- 化学式正确但系数配平错误，判“部分正确”并标“配平错误”；
- 计算题按步骤给分：关系式、代入、结果、单位、答句分别检查；
- 检查沉淀↓、气体↑、反应条件、电荷守恒和原子守恒；
- 手写识别不确定处标【识别存疑：xxx】，并把该题判为“存疑”，不臆造学生作答。

### Mock 演示数据

预置 3 名学生、4 份已批改作业、2 份待批改作业、3 条优秀答案和 1 份班级共性报告。即使不填 API Key，所有页面、按钮和主要流程也能完整演示。每次批改后，`common.js` 会重新汇总该学生的历史记录、等级趋势和薄弱点标签，自动写入学生档案。

## 五、课堂教学 · 实验仿真实验室怎么用

课堂教学模块已接入一个完全离线的“高中化学实验仿真实验室”，入口在 `classroom-teaching.html`，也可以直接打开 `virtual-lab.html`。

- 覆盖 7 个高中必做实验：氢气还原氧化铜、铁与水蒸气反应、铝热反应、实验室制取氯气、浓硫酸与铜、钠与水、铜与浓/稀硝酸。
- 进入后先选实验，再按左侧“实验操作台”的顺序操作；装置、现象、微观粒子和安全警报会同步变化。
- 每个实验都有安全前提提示，例如氢气还原氧化铜要先通 H₂ 排尽空气再点燃酒精灯。
- 页面左上角“← 返回”回到课堂教学模块；右上角“重置”回到当前实验初始状态。
- 不需要 API Key，也不需要联网；电脑、平板和手机浏览器均可使用。
- 该实验页面由同学提供，已做登录鉴权、返回入口和移动端适配后整合进本平台；实验现象与安全规则仍建议由任课教师课前复核。

## 六、课后答疑助手怎么用

课后服务模块已从占位页改为可运行的“课后答疑助手”：入口是 `after-school-service.html`，教师和学生都能用。它的目标不是直接给答案，而是先让学生写一句自己的思路，再按“方向提示 → 关键原理 → 规范解析”逐层推进。

- 支持题型：自动识别、工业流程、有机推断、实验探究、反应原理、计算题、其他综合；也可以只贴一小段题干，不必抄完整试卷。
- 支持输入：题目文字，或 JPG / PNG / WebP / GIF 图片（最多 4 张）。图片会在浏览器内压缩后发送；PDF 请先截图或导出为图片。
- 拆解结构：模型把题目拆成 3—6 个步骤，每一步先给“脚手架问题”，再按需解锁两层提示，最后才显示规范解析、关键方程式和易错提醒。
- 思路点评：学生写完自己的思路后提交，助手会先肯定，再指出还缺什么，并追问下一步；120 字以内，不直接代写。
- 靶向变式：全部步骤走完后，生成一道同方法、换情境的单选变式，点选项立即判分并显示解析。
- 答疑记录：只保存在当前浏览器，按账号隔离，最多 12 条；可以载入上次进度继续想，也可以清空。
- 独立思考率：统计“写过思路且没有直接看规范解析”的步骤占比；这个数字只用于课堂反馈，不作为成绩。

### 演示题与真实模型

不填 API Key 时，页面会明确提示“这次使用的是示例题，不是真实识别结果”，并使用 4 套内置演示题：

1. 废旧锂电池正极材料（LiCoO₂）回收制备 Co₃O₄（工业流程）；
2. 对羟基苯甲酸乙酯类有机合成（有机推断）；
3. SO₂ 与 O₂ 的平衡计算（反应原理，K = 11.25）；
4. NaHCO₃ 与 Na₂CO₃ 混合物热分解计算（计算题，NaHCO₃ 质量分数 84%）。

填了 Key 且没有开启“强制演示模式”时，才会把题目文字与图片发送给所配置的模型；调用失败、返回无法解析或超时，会自动回退到示例题，并在结果顶部显示原因，不会卡住页面。

### 关于同学源码包里的“免费模型”

同学的源码包（“循迹·化析”）里没有可直接使用的免费 Key，也没有内置免费模型的调用代码；它提供的是 OpenAI 兼容接口的调用方式。本平台把它改成了“任何 OpenAI 兼容多模态接口都能填”的形式，并在 `settings.html` 增加了 4 个一键填入的预设：

| 预设 | 模型名 | 接口地址 | 说明 |
| --- | --- | --- | --- |
| DeepSeek 4.1 Flash | `deepseek-flash` | `https://api.deepseek.com/chat/completions` | 默认；需要自己在 DeepSeek 开放平台创建 Key |
| 智谱 GLM-4V-Flash | `glm-4v-flash` | `https://open.bigmodel.cn/api/paas/v4` | 视觉模型，注册后通常有免费额度 |
| Gemini 2.5 Flash | `gemini-2.5-flash` | `https://generativelanguage.googleapis.com/v1beta/openai` | Google AI Studio 有免费额度，需自己申请 |
| 硅基流动 Qwen2.5-VL | `Qwen/Qwen2.5-VL-72B-Instruct` | `https://api.siliconflow.cn/v1` | 视觉模型，注册通常送额度 |

预设按钮只填表单，不自动保存；填写对应平台的 Key 后，再点“保存设置”或“测试连接”。免费额度、模型名和可用性会调整，以各平台控制台为准；不要共用他人的 Key，也不要把 Key 写进代码或截图。

> 浏览器直接调用第三方接口仍可能被跨域策略拦截；被拦截时页面会自动回退示例题并提示原因。准备正式演示时，优先在能正常访问该接口的网络环境下测试，或使用学校/自建的转发地址。

### 与同学作品的关系

“循迹·化析”提供的是题目拆解、逐层提示、思路点评和变式的产品思路与两套离线示例；本平台做了这些整合与改造：接入本平台的登录、角色导航和统一视觉；把题型从“工业 / 有机”扩展到多数高中化学题；增加 4 套演示题与图片输入；增加免费/兼容模型预设；增加历史记录、独立思考率和移动端适配。原作品署名与思路已在页面中注明，未直接打包或上传同学源码。

## 七、模型接口配置

进入 `settings.html`：

- **API Key**：只保存在当前浏览器的 `localStorage`，代码中没有写死任何 Key。
- **模型名**：默认 `deepseek-flash`，可修改；换成其他模型时，模型名要按对应平台填写。
- **接口地址**：默认 `https://api.deepseek.com/chat/completions`；如果填入以 `/v1` 结尾的地址，脚本会自动补全 `/chat/completions`。
- **模型预设**：设置页提供四个按钮，点一下只把模型名和接口地址填入表单，**不会自动保存**，确认后再点“保存设置”：
  - DeepSeek：`deepseek-flash` / `https://api.deepseek.com/chat/completions`
  - 智谱：`glm-4v-flash` / `https://open.bigmodel.cn/api/paas/v4`
  - Gemini：`gemini-2.5-flash` / `https://generativelanguage.googleapis.com/v1beta/openai`
  - 硅基流动：`Qwen/Qwen2.5-VL-72B-Instruct` / `https://api.siliconflow.cn/v1`
- **强制演示模式**：勾选后即使有 Key 也只使用预置演示数据，适合课堂展示或网络不稳定时使用。
- **测试连接**：用当前输入框中的 Key / 模型 / 地址测试；**测试成功后会自动保存**，避免“测试成功但忘记点保存”导致作业页仍用演示数据。

> 说明：源码分享包里没有可直接使用的免费 API Key，也没有内置免费模型额度。上面这些平台通常提供新用户试用额度或低价小模型，需要你自己注册账号、创建 Key，并遵守各平台条款。不要把别人的 Key 填进来共用。

调用方式为浏览器 `fetch`：请求头使用 `Authorization: Bearer <API Key>`，消息体包含文字提示词与 `image_url`（base64 Data URL）两部分；图片在发送前会在本地压缩。PDF 只记录文件名，演示版优先按图片批改；点击 AI 批改时若仍是 PDF，会提示“请上传图片”。

如果出现 401 / 402 / 404 / 429、网络错误、超时、返回内容为空或 JSON 无法解析，页面会显示原因并自动改用演示数据，不会卡住流程。批改请求第一次会使用 JSON 模式；若接口把不合规 JSON 替换成空内容，脚本会自动关闭 JSON 模式再重试一次，并把图片按高清晰度（detail=high）发送。

> 提示：真实 API 调用是否成功还取决于所填接口是否允许浏览器跨域请求。若在 `file://` 下被浏览器拦截，请改用本地静态服务器打开本文件夹，或把“接口地址”换成你自己可用的代理地址。演示数据不受影响。

## 八、数据、隐私与课堂使用

- 所有账号、学生档案、作业记录、优秀答案、报告与设置都保存在当前浏览器的 `localStorage`。
- 换电脑、换浏览器、清除站点数据或使用无痕模式，数据都会不可见。
- “设置 → 清空演示数据”会删除账号、档案、作业、报告和优秀答案，保留 API Key 与模型设置，并回到首页；首页会显示“恢复预置演示数据”按钮，可一键重建演示环境。
- 优秀答案墙只展示题目、匿名后的作答、教师评语、批次和日期，不显示姓名、学号或班级。
- 请勿录入真实学生姓名、学号、手写作业原图等敏感信息。比赛或公开展示前，请对素材做脱敏处理并取得授权。
- AIGC 评语只作为教学辅助，最终成绩与评价应由教师复核。

## 九、发给别人 / 手机打开

### 方式 A（推荐）：免费静态托管，得到一个 https 链接

这是最稳妥的方式：对方只需要点链接，不用安装任何东西，iPhone / Android 都能打开。

1. 在电脑浏览器打开 [Netlify Drop](https://app.netlify.com/drop)（可能需要登录一个免费账号）。
2. 把整个 `chemistry-platform` 文件夹拖进网页；不是只拖 `index.html`。
3. 等待上传和部署完成，会得到一个形如 `https://随机名字.netlify.app` 的网址。
4. 在手机浏览器打开这个网址，或把网址发给同事、评委、学生。入口会自动是 `index.html`。
5. 如果以后修改了文件，重新把文件夹拖一次即可更新；也可以在 Netlify 后台绑定自己的域名。

> 为什么必须上传整个文件夹：页面之间用普通相对链接跳转，样式在 `style.css`，公共脚本在 `common.js`。只上传一个 HTML 会出现“没有样式 / 点不动”的现象。

如果学校网络访问 Netlify 不稳定，可以把同一套文件夹上传到 GitHub Pages、Cloudflare Pages、腾讯云静态网站托管、阿里云 OSS，或请学校信息中心放到校内 Web 服务器。做法都一样：**保持目录结构不变，入口为 `index.html`**。

### 方式 B：直接发一个 HTML 文件（最省事）

`chemistry-platform-mobile.html` 是“单文件手机分享版”，约 667 KB，已经把 13 个页面、`style.css`、`common.js` 全部内联进去。

- 通过微信、QQ、邮件或网盘发送这一个文件即可，不需要再发其他文件。
- 接收者保存到手机后，用 Chrome / Edge / 手机 Safari 打开；页面内跳转、登录、演示数据都在这个文件里完成。
- 微信 / QQ 可能把 `.html` 当成附件，不允许直接预览：让对方点“用其他应用打开” → 选择浏览器。iPhone 的“文件”App 对本地 HTML 支持不稳定，优先用方式 A 的 https 链接。
- 单文件版和文件夹多页版的数据各自保存在浏览器本地，不会因为发送文件而把你这台电脑上的账号带过去；对方打开后会自动生成一套演示数据，可以直接用演示账号登录。
- 在手机上填写 API Key 也可以，但长 Key 容易输错；课堂展示建议不填 Key，直接用演示数据。

### 方式 C：同一 Wi-Fi 下临时访问（只适合现场）

电脑和手机连同一个 Wi-Fi，在电脑上用 VS Code 的 Live Server（或任意静态服务器）打开 `chemistry-platform` 文件夹，记下电脑的局域网 IP（例如 `192.168.1.20`）和端口（例如 `5500`），手机浏览器访问 `http://192.168.1.20:5500`。这种方式不能发给校外的人，电脑关掉就失效，适合课堂现场投屏或学生自带设备试用。

### 公开演示时的隐私提醒

- 公网链接上只放演示数据，不要放真实学生姓名、学号、手写作业原图。
- 每个访问者的账号、档案、作业和 API Key 都只保存在他自己的浏览器里，不会汇总到服务器；但这不代表可以收集真实隐私信息。
- 不要把 API Key 写进 HTML、截图或公开仓库；设置页保存的 Key 只存在当前浏览器。

## 十一、常见问题

**双击后登录了，换页面又要登录？**  
请确认所有 HTML、`style.css`、`common.js` 都在同一个文件夹内，并且是通过同一个浏览器打开。平台使用相对路径和同源 `localStorage`，不要只单独复制某一个 HTML。

**为什么真实 API 没返回结果？**  
先看设置页“测试连接”的提示。常见原因是 Key 无效、余额不足、模型名不对、接口地址不对、网络超时或浏览器跨域限制。任何失败都会自动回退演示数据，不影响课堂演示。

**上传了图片、也填了 Key，为什么结果还是演示数据？**  
按顺序检查三处：① 设置页点“测试连接”成功后会提示“设置已自动保存”，右侧状态应是“已配置 API Key”；② 作业页“上传与批改”卡片右上角应是绿色“API 已配置 · deepseek-flash”；③ 上传图片后要等缩略图和“图片已压缩至……”提示出现，再点“开始 AI 多模态批改”。如果仍未按图批改，结果上方会有一条黄色提示，写明失败原因（如 401、402、404、429、超时、JSON 无法解析）；把这句提示发给技术人员即可定位，不要发送 API Key。PDF 和 iPhone 的 HEIC 图片不支持，请先转成 JPG/PNG。

**PDF 为什么不能 AI 批改？**  
演示版优先支持 JPG/PNG 图片；PDF 只记录文件名。需要 AI 批改时请上传作业照片，或直接用“使用演示数据批改”。

**怎样恢复初始演示数据？**  
登录后进入“设置 → 恢复预置演示数据”。如果已经清空并退出登录，首页会显示“恢复预置演示数据”按钮，直接点击即可。

**数据会传到服务器吗？**  
除主动调用 DeepSeek 接口时发送作业图片和批改提示词外，平台没有后端，账号、档案、作业和报告都只存在本机浏览器。

**发给别人后，对方为什么看不到我的账号和作业？**  
这是正常的：账号、档案、作业和报告都保存在“当前这台设备、这个浏览器”的 localStorage 里，不会随网页文件一起发送。对方打开后会看到一套自动生成的演示数据，可以用演示账号体验；正式收集学生作业时，应部署到固定域名，并让学生各自在自己的浏览器里注册。

**手机打开单文件版是空白，或点不动？**  
先确认是用 Chrome / Edge / Safari 打开的，而不是微信 / QQ 的内置浏览器；再确认文件完整、没有被聊天软件改写成文本。iPhone 对本地 HTML 支持不稳定，建议改用方式 A 的 https 链接。

## 十二、在 GitHub Pages 上发布（可选）

如果想把网页变成一个可以发给任何人、手机直接打开的 https 链接，可以用 GitHub Pages：

1. 在 GitHub 新建一个 Public 仓库，例如 `chemistry-platform`，不要勾选自动生成 README。
2. 把本文件夹里的全部文件上传到仓库根目录，确保 `index.html`、`style.css`、`common.js` 在同一层；`.nojekyll` 也要上传，避免 GitHub 的 Jekyll 处理影响页面。
3. 打开仓库的 Settings → Pages，Source 选择 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等 1—2 分钟，页面会给出类似 `https://你的用户名.github.io/chemistry-platform/` 的地址。
5. 用手机 Chrome / Safari 打开这个地址即可。页脚与导航都是相对链接，放在仓库根目录时不需要改代码。

注意：GitHub Pages 只托管静态网页，不保存学生数据；每个浏览器仍然使用自己的 localStorage。真实模型 Key 只保存在访问者自己的浏览器里，不会上传到 GitHub。
